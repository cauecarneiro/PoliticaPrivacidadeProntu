# Política de Privacidade do Prontu!

Site de suporte do app Prontu!, com os termos de uso, a política de privacidade e o contato.

Site · GitHub Pages · 2026

[Prontu! na App Store](https://apps.apple.com/br/app/prontu/id6764180094) · [Código do app](https://github.com/cauecarneiro/Prontu) · [Site publicado](https://cauecarneiro.github.io/PoliticaPrivacidadeProntu/)

Não renomeie este repositório. A App Store aponta para o endereço do GitHub Pages deste site.

## O que faz
- Reúne numa página só os Termos e Condições de Uso e a Política de Privacidade do Prontu!, ambos atualizados em 28 de abril de 2026.
- Explica que os dados ficam no aparelho, que a IA roda localmente (Foundation Models) e que o acesso é por Face ID ou biometria.
- Trata da LGPD: o profissional é o controlador dos dados dos clientes e precisa da autorização deles.
- Mostra o contato do suporte.
